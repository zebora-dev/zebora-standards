# Fix patterns

Quote the real sentence, give a replacement. A scorecard that says "reduce em-dash usage" is useless; one that shows the sentence rewritten is actionable.

All examples below are real, taken from the 4As case study audit on 15 Sep 2026.

## Order of operations

Fix in this order. The first two do most of the work, and doing them first often resolves findings further down the list on their own.

1. Negative parallelism
2. Appositive elaboration (dashes **and** colons together — never dashes alone)
3. Bold, scare quotes, staged reframes
4. Stakes inflation and magic adverbs
5. Headings

## 1. Negative parallelism

Both halves say the same thing. Delete the negative half and commit to the positive claim, or split into two sentences that carry different information.

| | |
| --- | --- |
| ✗ | So for Zebora, the first challenge **wasn't running prompts. It was working out what should be measured** in the first place. |
| ✓ | The first three weeks went on deciding what to measure. We didn't run a prompt until that was settled. |

| | |
| --- | --- |
| ✗ | 4As **didn't have an authority problem so much as a differentiation problem**. |
| ✓ | ChatGPT trusted 4As. It just couldn't say what made 4As different from ANA or IAB. |

| | |
| --- | --- |
| ✗ | …a taxonomy built around real agency demand, **rather than simply turning the organisation's own terminology into prompts**. |
| ✓ | …a taxonomy built around real agency demand rather than 4As' own terminology. |

The third shows the cheapest version of this fix: keep the contrast, cut the padding inside it.

## 2. Appositive elaboration

Most glosses want to be a full stop. Some want a comma. A few are doing real parenthetical work and should stay.

**Dash → full stop** when the gloss is a complete thought:

| | |
| --- | --- |
| ✗ | But deeper analysis showed what the overall numbers hid **—** ChatGPT struggled to articulate why 4As was different. |
| ✓ | But deeper analysis showed what the overall numbers hid. ChatGPT struggled to articulate why 4As was different. |

**Dash pair → commas** when the aside is a simple list:

| | |
| --- | --- |
| ✗ | The 4As ranked ahead of its primary competitors **— ANA, AMA and IAB —** yet appeared in only around half of the relevant AI answers measured. |
| ✓ | The 4As ranked ahead of ANA, AMA and IAB, yet appeared in only around half of the relevant AI answers we measured. |

**Colon → delete the setup.** The clause before the colon is usually announcing a point rather than making one:

| | |
| --- | --- |
| ✗ | That difference was **decisive: a handful of generic prompts would have missed** both the differentiation gap and the weakness among independent agencies entirely. |
| ✓ | A handful of generic prompts would have missed the differentiation gap and the weakness among independent agencies entirely. |

**Keep** a dash that marks a genuine interruption or a real change of direction. Target 5–8 per 1,000 words, not zero.

## 3. Bold, scare quotes, staged reframes

**Bold facts, not opinions.** `49/100` and `~800 competitors` earn it. A claim does not.

| | |
| --- | --- |
| ✗ | `**measurable disconnect between 4As' growth strategy**` and how the organisation was actually being represented in AI |
| ✓ | a measurable disconnect between 4As' growth strategy and how the organisation was actually being represented in AI |

A bold span that closes mid-phrase, as above, is always a defect — fix it even when the count is green.

**Scare quotes and staged reframes: state the finding.** Both stage a question in order to answer it.

| | |
| --- | --- |
| ✗ | The diagnosis **shifted the question from "how do we increase our AI visibility" to something more specific:** how does 4As make its distinctive value clearer to AI… |
| ✓ | The useful question was no longer how to raise 4As' visibility overall, but how to make its distinctive value clearer to the audiences that matter most. |

## 4. Stakes inflation and magic adverbs

Say the smaller, truer thing. It reads as more confident, not less.

| | |
| --- | --- |
| ✗ | For an organisation as fragmented as 4As, that **diagnostic clarity is itself a significant outcome**. |
| ✓ | For an organisation this fragmented, knowing that was worth the audit on its own. |

Magic adverbs delete cleanly: *genuinely* difficult → difficult. *Noticeably* stronger → stronger. *Essentially* no visibility → no visibility. A full **360°** view → a full view.

## 5. Headings

Re-cut section headings as statements. Leave FAQ questions alone — they are question-shaped on purpose and they earn citations.

| | |
| --- | --- |
| ✗ | **What Zebora uncovered:** an authority AI couldn't differentiate |
| ✓ | An authority ChatGPT couldn't differentiate |

Two re-cuts is usually enough to clear the signal. Don't convert all of them — an all-statement page reads as flat as an all-question one.

## What not to "fix"

Writers over-correct once they have a list. State these explicitly in every scorecard.

| Leave alone | Why |
| --- | --- |
| Rule-of-three lists at normal density | "authority, trust and clarity" is English, not a tell |
| Question-shaped FAQ headings | Highest-value AEO field on the page |
| Body-to-FAQ repetition | FAQ answers must stand alone when extracted |
| Hedging on measurement claims | Overclaiming is a worse failure than sounding synthetic |
| Every last dash and colon | Zero is as unnatural as twelve per thousand |
| Admissions of failure | "Not yet measured" is the most human thing on a page. Never edit it out |

That last row matters most. The strongest human signal in the Zebora case studies is that they say plainly when nothing has been measured yet. A writer trying to raise their score will be tempted to smooth those sections. Tell them not to.
